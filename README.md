# Секундомер онлайн

Бесплатный онлайн-секундомер для точного измерения времени в браузере — без установки и регистрации.

## Возможности

- Отсчёт с точностью до сотых секунды.
- Старт, пауза, продолжение и сброс.
- Фиксация кругов с отображением времени круга и общего времени.
- Выделение самого быстрого и медленного круга.
- Сохранение состояния в браузере после обновления страницы.
- Полноэкранный режим и управление с клавиатуры: пробел — старт/пауза, L — круг, R — сброс.
- Адаптация для телефона, планшета и компьютера.
